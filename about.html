What we value

The principles behind PutForm

Six ideas shape every feature we ship and every line of code we write.

🎯

Clarity first

Powerful tools shouldn't feel complicated. We strip away noise so you can focus on the response, not the interface.

🔐

Privacy by default

Your data belongs to you. We use cookie-based sessions, encrypted transport, and never sell or share your submissions.

⚡

Speed matters

Forms load in milliseconds, submissions land instantly, and the API responds fast enough to feel invisible.

🛠️

Built for builders

REST endpoints, session checks, and clean JSON — everything a developer needs to plug PutForm into any product.

🌍

Accessible everywhere

Light and dark themes, responsive layouts, and keyboard-friendly navigation across every page we ship.

🤝

Honest by design

No dark patterns, no confusing pricing tiers. Just a clean product that does exactly what it promises.

The journey

How we got here

From a weekend prototype to a platform trusted by thousands of teams.

2023 · The beginning

A simple idea

PutForm started as an internal tool to collect feedback from early users of a side project. It worked so well we decided to share it.

2024 · Going public

First public release

The form builder launched with publishing, response limits, and a lightweight dashboard. Within months, thousands of forms were created.

2025 · Developer API

Opening the platform

We shipped a REST API with cookie-based sessions so teams could embed PutForm submissions directly into their own backends.

2026 · Today

Where we are now

PutForm powers surveys, intakes, and feedback loops across 40+ countries — with the same focus on clarity we started with.
